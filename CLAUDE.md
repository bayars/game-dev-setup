Hobby game (2D or 3D, undecided). Laptop is the control plane (no GPU); heavy work runs on the GPU server `gpubox` per the `gpu-server-delegation` skill (`.claude/skills/`).

|---|---|
| Blender (server) | 4.2.23 LTS, `/opt/blender` |
| Godot | 4.7.2-stable (laptop and server must match), `/opt/godot` on server |
| NVIDIA driver (server) | 550.163.01, runfile install, frozen |

## Layout

`godot/` Godot project; `art-src/` .blend and raw textures (LFS); `scripts/` pipeline scripts; `docs/` server baseline and maintenance; `renders/`, `build/` gitignored.

## Rules

- Work on feature branches; never push to `main`; review diffs before merging.
- Never edit files on the server by hand. Fix locally, push, rerun.
- GPU or heavy jobs go through the skill. Never touch NVIDIA drivers, kernel, apt holds, or run `apt upgrade` on the server.
- Do not commit renders or builds. Git LFS only for source art (`*.blend *.psd *.exr`).
- Server: `ssh gpubox` (10.0.0.224, user `safa`, key `~/.ssh/gpubox`). Repo checkout at `~/work/game`, logs in `~/work/logs`.
- Stop and summarize after two identical failures.

## Git access

- Laptop pushes with a dedicated write deploy key `~/.ssh/github_game` (set in this repo's `core.sshCommand`).
- Server fetches with a read-only deploy key via the `github-game` SSH alias (`~/.ssh/github_game_deploy` on the server). It cannot push.
- `~/.ssh/gpubox` is only for logging in to the server.

## Game: Dodger (2D one-screen arcade, Godot)

Start screen (Space/Enter). Move the blue square (WASD/arrows), collect yellow coins (+10), avoid red squares: 3 lives, 1 s invulnerability after a hit. Score = 10 per coin + seconds survived. Best score is saved to `user://highscore.cfg` (not written during `--selftest`). Space/Enter restarts. Art is Blender-made: sprite scenes are Python scripts in `art-src/sprites/` (`player`, `hazard`, `coin`, `background`, shared `common.py`), rendered on the server with `scripts/delegate.sh sprites [name|all] [size]` (final sheets use size 96; 256 for design previews). Output `build/sprites/*_sheet.png` (8 frames, 1 row) and `background.png` is copied into `godot/assets/sprites/` and committed from the laptop. Sprites display at scale 0.5.
- Run: `godot --path godot` (editor: `godot --path godot -e`)
- Screenshots without a window: `xvfb-run -a -s "-screen 0 960x540x24" godot --path godot --rendering-driver opengl3 --write-movie out.png --fixed-fps 30 --quit-after 240 -- --autostart`
- Headless loop check: `godot --headless --path godot -- --selftest` prints `SELFTEST_OK` (also works on the exported binary: `game.x86_64 --headless -- --selftest`)
- Layout: `godot/scenes/` (`main.tscn`, `faller.tscn`), `godot/scripts/` (`main.gd` loop, `player.gd`, `faller.gd`). Input uses physical key checks (no InputMap yet). `-- --autostart` skips the start screen.

## Game 2: Walk Home (3D story, `godot-3d/`)

A person walks up a path at dusk to a house and opens the door (WASD, mouse look, Shift run, E to open). Title portrait (close long-lens camera in front of the walker, front fill light, idle animation with blinks; the camera swings behind on Space), two story lines, objective, "Welcome home", end card (R again, Esc quit).
- All models are Blender scripts in `art-src/models/` (`person`, `house`, `tree_pine`, `tree_round`, `lamp`, shared `common.py`), built and exported on the server: `scripts/delegate.sh models [name|all]` -> `build/models/<name>.glb` (+ `<name>_preview.png`, a Cycles preview on the P4). Move the `.glb` into `godot-3d/assets/models/` on the laptop and commit. `-convcolonly` objects become collision shapes in Godot; the house door swings on the Empty `DoorHinge`.
- The person (`art-src/models/person.py` + `face.py`) is a rigged character: skeleton (Hips..Head, arms with hands, legs with feet/toes, `Eye_*`, `LidUp_*`/`LidLo_*`), one smooth skinned body (Skin modifier + heat-map weights) with fingers, jacket details, scarf, backpack, shoes. The head (`face.py`) is sculpted at real proportions (41k-vertex mesh displaced by anatomical features: brow ridge, sockets, nose, cheekbones, lips, chin, jaw, with a near-vertical lower-face profile), with real eyelid openings and rigged eyelids that blink, textured eyeballs (painted iris/limbus/pupil + catch-light), upper lashes, shaped ears, a painted 1024px skin texture (blush, under-eye shadow, lips, individual eyebrow hairs, freckles) registered to the sculpt by front projection, and ~330 tapered hair strands over a scalp shell with a side parting. Keyframed actions `idle_loop` (with blinks), `walk_loop`, `run_loop`, `open_door` import in Godot as `idle`, `walk`, `run` (looping; Godot strips `_loop`) and `open_door`. `delegate.sh models person` also renders pose sheets `build/models/person_{walk,run,idle,door}_sheet.png` and face close-ups `person_face_{front,34,side,blink}.png` to review the motion and face before importing. `player.gd` plays them and scales walk/run speed to the real velocity (no foot sliding).
- Rendering (Forward+ / Vulkan, `scripts/graphics.gd` `Graphics` node): physical sunset sky, soft sun shadows, SDFGI, volumetric fog, SSAO/SSIL, bloom, AgX tonemap, portrait depth of field, film-finish shader (`shaders/post.gdshader`), ground shader (grass + gravel path, `shaders/ground.gdshader`), ~26k grass clumps (`shaders/grass.gdshader`), skin subsurface scattering. Materials are PBR sets (albedo/normal/rough) baked in Cycles by `scripts/delegate.sh textures [name...]` from the recipes in `art-src/textures/pbr.py` (seamless via 4D torus noise), copied to `godot-3d/assets/textures/` (LFS) and applied by Blender material name (`HOUSE_MATS`/`TREE_MATS` in `main.gd`, triplanar, no UVs needed). Quality LOW/MEDIUM/HIGH/ULTRA: key G, `--quality=ultra`, default by GPU (discrete NVIDIA/AMD ULTRA, software LOW, else MEDIUM). Intel UHD manages ULTRA at only ~3 fps; use MEDIUM there. Screenshots need a real Vulkan display: `DISPLAY=:0 godot --path godot-3d --rendering-driver vulkan --write-movie out.png --fixed-fps 30 --quit-after N -- --quality=ultra --autoplay` (the server has no X, so Godot screenshots run on the laptop; the P4 does the Blender/Cycles work).
- The world, story state machine and UI are built in code: `godot-3d/scripts/main.gd` (`Phase` enum TITLE, WALK, AT_DOOR, OPENING, END) and `player.gd`.
- Headless check: `godot --headless --path godot-3d -- --selftest` plays the whole story fast and prints `SELFTEST_OK`. `-- --autoplay` plays it at normal speed; `--start-z=-2` spawns near the house (quick screenshots, see the xvfb recipe above).
- Pitfall: point lights placed within ~1 m of a wall blow it out to white; keep them away or use emissive materials.

## Game 3: Off the Books (18+ isometric 3D story, `godot-house/`)

Two undocumented handyman brothers (Nico, Tomas) renovate a family home; on day 2 an accident kills Daniel, and they must stage it before the four other residents find him. Full story, systems, endings and milestones: `docs/game3-design.md`. Concealment and investigation are game-defined rules only (tokens, timelines, witness memory), never real forensic techniques.
- Milestone 1 (greybox) done: house ground floor built in code (`scripts/house.gd`, rooms/walls/props tables, navmesh baked one physics frame after build, cell size 0.1 to match `[navigation]` in project.godot), isometric camera (`iso_camera.gd`: narrow FOV, fixed 45 degree yaw (no turning, removed in the feel pass), wheel zoom), wall cutaway (`shaders/wall.gdshader`, per-instance `cut`), actors with click-to-move navigation (`actor.gd`; people collide only with the house, layer 2 / mask 1), residents on schedules (`npc.gd`), right click sends Tomas, F follow/stay. Feel pass: you are always Nico (Tab switching removed), WASD removed; hold the left button to keep walking to the cursor (`Main.walk_toward`, paths only, so nobody is pushed into a wall). Rendering reuses `graphics.gd` and textures from Walk Home.
- Milestone 2 (day 1 tutorial) done, then reworked: `day1.gd` (jobs as install steps, intro/pay dialogue, hints, Daniel's lines), `job.gd`, `carryable.gd` (solo carry: slow, noise rings every 0.8 s; pair carry: fast, silent, helper walks behind via `Actor.lead`), `dialogue.gd`, residents hear noise into `Npc.noticed` (the Seen log, folded per sound by `Npc.summarize` on the end card). Job list buttons send the other brother: solo-able jobs he does on his own (24 s, hotspot by hotspot with the right clip and tool), two-person jobs he goes to hold, carrying he refuses alone.
- Install view (`install.gd`): the camera moves in (`IsoCamera.focus_on`, wheel zooms 3-16 m), the tool bag is a tray (`hud.gd`, icons from `assets/icons/`), steps are `{tool, text, kind: spots|hold|order, seconds}`; hotspots are picked in screen space. `worksite.gd` owns the hotspots and every visible result per job (`spots`, `apply(job, step, i, t)`, `finish`). Wrong tool or order is refused; a hammer or a wrong wire is loud (`Install.mistake`).
- Cast (milestone 3): `art-src/models/people.py` holds one profile per person (Nico, Tomas, Daniel, Linda, Robert, Sofia, Rose: body shape, face, hair style, clothes, extras such as tool belt or glasses, stoop); `person.py` builds any profile (`PERSON_PROFILE`, default `walker` = Walk Home's look). Build: `scripts/delegate.sh models [--cpu] [--sheets=all|clip,...] person_<id> ...` (`--cpu` when ollama holds the shared P4's memory) -> `build/models/person_<id>.glb` + `_preview.png`, `_face_front/34.png` and optional clip sheets. Copy the .glb into `godot-house/assets/models/` (LFS). Every model is 1.78 m with the same rig and clips (`People.CLIPS`: walk/run/idle, work and carry clips, `search crouch phone sit react_fall limp`); `people.gd` scales each to its height (keep in step with people.py). `Actor.idle_clip` sets what someone does standing still. Ragdoll: `Actor.go_limp(impulse)` builds PhysicalBone3D capsules on 12 bones (layer 4, collides with the house) and simulates; `ragdoll_settled()`, `body_position()`.
- Props and tools: `house_props.py` (rounded furniture and job-site props, one root `P_<Name>` each, placed with `House.prop()`), `tools.py` (tools and parts `T_<id>` gripped at the origin + tray icons). Build: `scripts/delegate.sh models house_props tools`; copy the .glb into `godot-house/assets/models/` and `build/models/tools_icon_<id>.png` to `godot-house/assets/icons/<id>.png`. Review `house_props_preview.png`, `tools_sheet.png` first.
- House: two floors (`House.UP` = 2.9; the upper floor node is hidden while the controlled brother is downstairs), stairs in the east room (visual rounded steps plus one walkable ramp collider; the flight is closed at the side so it is entered from the end), walls and floors are `RoundBox` meshes (rounded edges), `wall.gdshader` takes a per-instance `base` floor height. Day 2's work (and the accident) is upstairs in Daniel's room. Colliders that the navmesh must avoid have to be children of the `House` node (the bake only parses its children); furniture added later calls `House.rebake()`.
- HUD (`hud.gd`, `ui_theme.gd`): one palette and type scale, status pill, job list (open first, finished folded into one line, J folds it), brother cards with order buttons, key-cap prompt for the one current action, toasts, F1 controls overlay, centred end card.
- Navigation pitfalls (solved, keep): navmesh sits ~0.2 m above the floor, so agents use `path_height_offset = 0.2` and `path_desired_distance = 0.25` (larger values cut doorway corners into the wall ends); `is_navigation_finished()` is ignored for 2 frames after `go_to`; new `class_name` scripts need `godot --headless --path godot-house --import` once before the self-test.
- Day 2 (milestones 4-6): `Game` (static state: day, case, options, save in user://save.cfg), `Story2` (morning -> accident cut-scene -> choice -> cover-up -> discovery -> police -> ending), `Worksite2` (Daniel's room: closet studs/drywall, skirting with the nail gun, ceiling light), `Coverup` (body as a `BodyLoad`: L lifts/drags him, together quiet, alone loud with drag-mark tokens; `Token` signs to tidy or take; stage scenarios with setup spots; residents' search plans (`Npc` SEARCH/CHECK/TALK/GATHER/AWAY modes, pauses that ring his phone); K keep a searcher busy, C tidy, P switch off his phone; Tomas's stress; the work alibi; sight lines -> found/caught), `Investigation` (pure rules -> checks and ending), `Cinematic` (letterbox camera, fades, cards, check rows). Data: `resources/accidents/*.tres` (`AccidentCase`: stud, nailgun, sheet) and `resources/scenarios/*.tres` (`StageScenario`: stairs, ladder, storage_nailgun, garage_nailgun, bathroom); new cases need no code. Endings: clean, shadow, timeline, trail, doesnt_add_up, found_early, caught, tomas_breaks, fall_nico, fall_tomas, truth.
- Title screen `scenes/menu.tscn` (main scene): content warning on first launch; the story buttons follow the save (`Menu.story_buttons()`): a new player gets only Play (day 1), after day 1 Continue (day 2), and once day 2 has been played to an ending (`Game.day2_done`) a choice of Day 1 / Day 2. Options (soften the accident, volume, graphics). End cards have clickable buttons (and keys): day 1 goes on to day 2 (replay only once day 2 has been seen); a failed day 2 ending (anything but `Investigation.GOT_AWAY`: clean, shadow) asks "Try again?" (R same case, N another accident, M menu). Esc in game: pause menu. Command-line flags skip the menu. Menu check: `godot --headless --path godot-house -s res://tests/menu_test.gd` runs the menu for each save state (the real save is untouched), clicks through the warning and Options and checks the buttons, the focus and that nothing covers a button; prints `MENU_OK`. Pitfall: a full-screen Control (e.g. a `CenterContainer`) catches every click under it unless `mouse_filter = MOUSE_FILTER_IGNORE`; the headless window is 64x64, so UI tests set `get_root().size` first. Don't capture with `DISPLAY=:0` while the user is typing: the window takes their keys.
- Sound: `art-src/audio/make_sounds.py` synthesizes every sound (numpy + ffmpeg for the Ogg loops) into `godot-house/assets/audio/`; `Sfx` plays them (missing files are silent). Police cast: `person_hale`, `person_officer`.
- Headless check: `godot --headless --path godot-house -- --selftest` plays all of day 1 (wiring and drywall through the real install input, wrong tool first; the measure job walks upstairs) and prints `SELFTEST_OK`. Watch it: `DISPLAY=:0 godot --path godot-house --rendering-driver vulkan --write-movie out.png --fixed-fps 4 --quit-after 2000 -- --selftest --quality=medium`.
- Play-test: `godot --headless --path godot-house -- --playtest [--only=install,reach,hold,tour]` checks what a player sees and where they can go: every install hotspot on screen, outside the HUD and not hidden (people in front of the work fade out), every room and job reachable, holding the button towards any wall never leaves Nico stuck or inside a wall, no two HUD panels overlap. Prints `PLAYTEST_OK`. With a display, `DISPLAY=:0 godot --path godot-house --rendering-driver vulkan -- --playtest --quality=medium --shots=<dir>` also saves a screenshot per install step and tour state.
- Day 2 self-test: `godot --headless --path godot-house -- --selftest --day=2 --case=stud|nailgun|sheet --plan=clean|trail|truth|early|caught` plays day 2 through the real controls and checks the ending (clean -> clean, trail -> trail, truth -> truth, early -> found_early, caught -> caught); prints `SELFTEST_OK day2 ...`. `--shots=<dir>` (with a display) runs it in real time and saves a screenshot every 1.5 s. Rules: `godot --headless --path godot-house -s res://tests/rules_test.gd` prints `RULES_OK`. Play-test day 2's install views: `-- --playtest --day=2 --only=install`.
- Test what ships: `godot --headless --path godot-house --export-pack "Linux" <dir>/test.pck`, then `godot --main-pack <dir>/test.pck --headless -- --selftest ...` (run outside the project; no export templates needed). Exported builds differ: `PackedStringArray` properties in our .tres data came out empty (use plain arrays), and nodes instanced but never added to the tree (prop/tool libraries) crashed the release build on quit (free them in `_exit_tree`).
- Physics is Jolt (project setting): the GodotPhysics ragdoll pushed through thin walls.
- Cast check: `godot --headless --path godot-house -s res://tests/people_test.gd` lines up all seven people, plays every clip on every model and drops Daniel as a ragdoll; prints `PEOPLE_OK`.

## Releases

`scripts/release.sh <project_dir> <version>` (e.g. `godot-3d 0.1.0`) builds Linux and Windows on the server and copies the zips to `releases/<name>-<version>-<platform>.zip`, stored in Git LFS (`releases/*.zip`). Commit them from the laptop. The server checkout excludes `releases/*` from LFS fetches. Windows builds are only checked structurally (PE header); they cannot be run on this machine.
Builds: `scripts/delegate.sh build_linux [project_dir]` / `build_windows [project_dir]` (default project_dir `godot` = Dodger), output `build/<config/name lowercased>-<platform>.zip`.
